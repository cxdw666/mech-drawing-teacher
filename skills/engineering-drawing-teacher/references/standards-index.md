# 标准索引（只放"去哪查"，不放数值表）

> **本文件不收录标准正文与数值表。** 原因有二：数值表体积大、易过期；且标准文本有版权，开源仓库里应当只放**索引与检索方法**，具体数值由使用者按现行版本自备。
> 提示词（`prompts/core-*.md`）负责「知道去哪查、查完怎么用」，知识库负责「查到什么」。把 500 页标准塞进提示词，模型只会记住开头三页。

## 怎么用这份索引

1. 模型给出结论时，要求它写出标准号。**标准号必须出现在下表里**；不在表里的一律标 `[待核]`。
2. 需要具体数值（线宽、公差、Ra 优先值、剖面符号画法）时，按"该查哪一本"去查现行版本，不要相信模型的记忆。
3. 标准号不带年份：年号随版本变动，写年份反而容易写成过期版本；版本确实必要时标 `[待核版本]`。

## 使用者自备清单（仓库不提供，需按现行版本查）

- [ ] 线型全表（GB/T 4457.4）：各线型的名称、宽度、用途
- [ ] 剖面符号表（GB/T 4457.5）：不同材料的剖面线画法
- [ ] 标准公差数值表（GB/T 1800.1）：IT 等级对应的数值
- [ ] 基本偏差表（GB/T 1800.1）：a–zc / A–ZC 的偏差值
- [ ] Ra 优先值系列（GB/T 131）：0.012–100 的取值
- [ ] 螺纹标准尺寸表（GB/T 196/197 等）：M 系列的螺距与小径
- [ ] 优先数系（GB/T 321）：R5/R10/R20/R40

> 这些表格的数值一旦抄错，比不写更危险（学生会把错的当标准记）。所以本仓库只教「查哪本、怎么用、怎么标 `[待核]`」。
