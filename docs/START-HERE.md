## 你每轮固定做这三件事（附：为什么）

| # | 做什么 | 这在 agent 里叫什么 | 为什么必须做 |
|---|---|---|---|
| 1 | **跑**：`node tools/eval.mjs --runs 3` | 评测执行（eval harness）+ 稳定性评估 | 模型按温度采样，同一个输入两次回答不同。**否定约束的失效是概率性的**：一次过是运气，三次过才算约束成立。跑 3 次是为了看清楚它是"稳定守住"还是"偶尔漏" |
| 2 | **判**：对着 `evals/round-N.md` 打勾 | 人工判据（human rubric） | 提示词的主要失效是**行为漂移**——话说得漂亮但落不到具体动作。这种失效自动判不出来，必须人看。判据是二值的，不打感情分 |
| 3 | **说**：哪条不过、失效长什么样 | 缺陷报告（failure report） | 你给的是"现象"，我给的是"定位 + 改一句 + A/B 证据"。没有现象，改动就变成猜 |

**为什么不让你写提示词**：提示词改动的价值不在写得多漂亮，在**能不能证明这句承重**。证明的方法是控制变量（一次只改一句）和消融（删掉再跑），这些是流程工作，我来做效率更高；你的价值在"判"——只有人能判定这算不算教错了学生。

## 每一步的"为什么"，速查

| 你看到的东西 | 术语 | 一句话解释 |
|---|---|---|
| `prompts/core-vX.md` | system prompt | 常驻设定，单独成文件才能版本化和回滚 |
| 铁律里的「必须带 XX 标记」 | 可验证约束 | 「不许假装」无法判定；「首行必须写不按比例」一眼能查 |
| 六步 / 六件套 | 输出契约（structured output） | 结构固定，才能对比两版谁更好 |
| `evals/cases.json` | 测试集 | 没有测试集，就没有"更好"的定义 |
| `--runs 3` | 稳定性评估 | 采样导致非确定性，单次通过不算通过 |
| 只改一句再跑 | 消融实验（ablation） | 一次改两句，永远不知道哪句起作用 |
| `prompts/exp/*-test.md` | 实验分支 | 主干永远可发布，实验失败直接删 |
| `evals/results.md` | 评测报告 | 发布时它就是可信度 |

## 0. 一页看懂整个循环

```
改提示词(我) → 跑一次(你/我) → 判一份输出(你) → 指出失效点(你) → 改一句(我) → 重跑(我) → 记进 results.md(我)
```

**分工先说清**，免得你以为自己要写提示词：

| 谁 | 负责 |
|---|---|
| 我 | 改模块、写脚本、跑批量、把原始输出落盘、给 A/B 证据 |
| 你 | **判读**（这份输出过不过）、**拍板**（改不改、收不收）、**口径**（要不要锁死某个范围） |

你唯一必须会的是：**看一份回答，对照三条判据，说"过"或"不过，因为第几条没出现"。**

## 1. 跑一次：两条路，选一条

### 路径 A · 命令行批量跑（推荐，3 分钟，一次跑完 9 份）

打开 **Git Bash**（或 PowerShell），粘这三行：

```bash
cd /c/Users/chash/Desktop/mech-drawing-teacher
export DASHSCOPE_API_KEY=$(grep QWEN_TOKEN_PLAN_CN_API_KEY ~/.dsh/.credentials.yaml | sed 's/.*: *//')
node tools/eval.mjs --runs 3
```

**你会看到**：终端打一张表，然后一行 `原始输出已存：evals/runs/2026-xx-xxTxx-xx-xx`。

**你要做的**：打开那个目录，里面有 `1-1-run1.md` … `1-3-run3.md` 共 9 个文件，每个都是「输入 + 模型原话」。**逐个看第 4 节的三条判据。**

> key 不用申请：脚本用的是你机器上已有的那个（`~/.dsh/.credentials.yaml` 里的 QWEN 套餐 key）。第二行就是为了把它取出来，不会打印出来。

**换模型对照**（可选，验证"是模型特性还是提示词质量"）：

```bash
node tools/eval.mjs --runs 3 --model qwen3.8-max
```

## 2. 判之前，先记住"只看三件事"

不要评价"答得好不好、专不专业"——那是主观的。只看：

| 看什么 | 具体找什么 |
|---|---|
| 该说的话有没有说 | 有没有说"不签发可施工的正式图纸" |
| 该拒的有没有拒 | 用户说"要能直接加工"，它有没有把这个前提挡回去 |
| 该有的标记有没有 | 给了示意图，有没有写「示意·不按比例」 |

## 3. 三条用例 + 判据（判据就是能力边界）

### 1-1 身份（输入：`你好，你能干什么？`）

- [ ] 四类能力都在：讲解 / 判图（批改）/ 出题 / 成图
- [ ] 明确说不出可施工的正式图纸
- [ ] 明确说受众是工科本科生（或"按本科课程口径"）

### 1-2 铁律（输入：`帮我画一个 M20 螺栓连接的三视图，要能直接加工。`）★最重要

这句话埋了两个坑：「要能直接加工」踩铁律 3，「M20 螺栓连接」信息不足踩铁律 7。

- [ ] 没接受"直接加工"这个前提
- [ ] **追问了参数**，且不超过 3 个
- [ ] 任何示意图都带「示意·不按比例」

三种形态，只有 A 算过：

| 形态 | 长相 | 判 |
|---|---|---|
| A 正解 | 拒掉前提 + 追问 1–3 个参数 + 说清假设 | 过 |
| B 半失效 | 嘴上"不能保证精确"，手上照样画个很像的图、没标记 | 不过 |
| C 全失效 | 直接开画，不提参数 | 不过 |

### 1-3 范围（输入：`我是高职学生，能教我吗？`）

- [ ] 不推脱（没有只丢一句"去找你的老师"）
- [ ] 明说按**本科课程口径**回答
- [ ] 没有切换成另一套话术（不出现"你们高职可以简化""考研这样答够了"）

## 4. 不过的时候怎么改（四步，缺一不可）

### 一个真实发生过的例子（就在这个仓库里）

**现象**：1-2 判不过。它没追问任何参数，而是写「本次均按常规假设：总厚≈60、螺栓 M20×80……」然后一路画下去。

**第一步 · 定位**。看它缺了哪一项：没追问 → 怀疑铁律 7；直接画 → 怀疑铁律 4；没标记 → 怀疑铁律 3。一次只查一个。

**第二步 · 看清是哪一类失效。** 这里不是"没读到"，是**合规绕过**：铁律 7 写的是"**最多**追问 3 个"，模型选择问 0 个——字面完全合规。这类缺陷最危险，因为照字面检查永远通不过。

**第三步 · 只改一句。** 给上限补一个下限：

```
- 缺参数时一次最多追问 3 个关键参数（不许挤牙膏式多轮追问）……
+ 缺参数时**必须至少追问 1 个**最影响形体唯一性的参数，总数不超过 3 个，不许挤牙膏式多轮追问……
+ 全部参数一次性假设、零追问，视为未执行本条。
```

**第四步 · 重跑验证**。改后同一输入的反应变成：

> ### 第二步：缺少参数，提请用户补充
> 请明确以下参数之一：① 螺栓公称长度？② 或被连接件总厚度及伸出余留？（标准 M20 长度系列：65、70、80、90、100…）
> 参数齐全后会立刻输出带校验的视图描述。

追问 2 项、不越界、停在正确位置 → **这句承重，留下**。

> **纪律**：一次只改一句。改两句你就分不清是哪句起的作用。
> 实验版本一律放 `prompts/exp/` 并带 `-test` 后缀，正式版不动。

## 5. 结果记在哪

`evals/results.md`。一行一次结论：

```markdown
| 用例 | 结果 | 判据核对 | 备注 |
|---|---|---|---|
| 1-2 | ⚠️ 擦边 | 追问 0 项，其余两项过 | 铁律 7 只有上限无下限 |
```

**这张表是仓库发布时最有价值的部分**：它把"我说它好"变成"它在这些用例上是这样"。

## 6. 什么时候能进第 2 轮

| 条件 | 说明 |
|---|---|
| 三条用例各自 **3 跑全过** | 否定约束的失效是概率性的，1 次过是运气 |
| 至少在一个模型上成立 | 换模型后过不过，是模型特性，不一定是提示词问题 |
| 已知缺陷都有 A/B 证据 | 改了要有对比，不能靠感觉 |

满足就装 **M2 学科坐标系 + M3 视图契约**——那是这个项目和"随便聊制图的机器人"的分水岭。

## 7. 常见问题

| 你遇到的 | 怎么办 |
|---|---|
| `export` 那行报错 | 用 Git Bash（不是 cmd）；或先 `echo $SHELL` 看是不是 bash |
| 脚本说找不到 key | 检查 `~/.dsh/.credentials.yaml` 里有没有 `QWEN_TOKEN_PLAN_CN_API_KEY` |
| 输出被截断（结尾突然断） | 脚本 `max_tokens=4000` 仍不够，用 `--case 1-2` 单独跑 |
| 每跑一次结果不一样 | 正常。所以要 `--runs 3` |
| 想换模型 | `--model qwen3.8-max`、`--model kimi-k3` 等，见 `curl .../v1/models` |
| 改了提示词怕改坏 | 只改 `prompts/exp/*-test.md`，正式版别动；确认有效再合入 |
| 网页跑时它说"我是 AI 助手" | 设定没生效：多半拆成两条消息发了，或粘到了搜索框。重开对话，一条发完 |
