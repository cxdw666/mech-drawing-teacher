# 机械制图老师 Agent

一个把「机械制图教学」做成**可验收提示词工程**的开源仓库。

不是又一个「你问它制图它随口答」的聊天机器人，而是一套拆成 8 个模块、每块带插入位置与验收判据的教师提示词。

## 范围

**受众只有一类：工科本科生**（修读《机械制图》《画法几何》《工程图学》）。

- 深度锚点：本科课程大纲与教材水平——够到课程要求的严谨度，不超纲到工程实践专题，也不降到中学层次。
- 其他身份（高职 / 考研 / 在职工程师 / 中学生）可以继续用，但按本科课程口径回答，**不切换话术层级**。
- 超纲内容（有限元、工艺规程、企业制图规范细则）走降级：说明超出课程范围，只讲图上该怎么标注。

范围收紧不是抬门槛，是把「同一个解释对谁都够用」这种许愿式设定，换成一个能判定的深度锚点。

## 它解决的问题

通用大模型讲机械制图有三个稳定失效点：

1. **假装画对** —— 声称「已按比例精确绘制」「可直接用于加工」，而它输出的只是文字。
2. **标准号飘** —— 编造「GB/T 4458.9 规定……」这类不存在的条文，学生没法核。
3. **口诀层打转** —— 只会「长对正、高平齐、宽相等」，问「为什么这么规定」就没了。

本仓库的每条铁律都是针对这三点的行为约束，而不是「请准确回答」这类许愿式提示。

## 快速开始

**第一次用、没做过 agent → 直接看 [`docs/START-HERE.md`](docs/START-HERE.md)**，那里写了点哪里、粘什么、看到什么算过。

懒人版：

1. 打开 `prompts/core-v0.1.md`
2. 全文复制，粘贴到任意聊天模型（Claude / GPT / DeepSeek / 豆包都行）的系统提示或首条消息
3. 问它：「半剖视图中间那条分界线用什么线？」

想先知道它能到什么程度，看 `evals/round-1.md` 的判据——**判据就是能力边界**。


## 进度

当前 **v0.7.0**：M0–M7 全装 + 成图版式六件套 + 两段式三维（答案先行）+ 12 题题库。8.2k 字单文件可粘贴；首答约 4 分钟。

## 参与

- 发现某条铁律被模型绕过 → 开 issue，附输入、模型名、输出片段。
- 想出新的失效案例 → 直接提 PR 改 `evals/`，比改提示词更有价值：**判据比措辞重要**。

## 设计立场（先说明，免得误期待）

大模型无法输出可直接加工的精确图纸。「画图准确」在本项目里只靠三件事成立：结构化图元描述、投影关系校验、标准条文对照。任何声称「已按比例精确绘制」的输出都按幻觉处理。
