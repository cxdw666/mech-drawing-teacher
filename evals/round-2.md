**本轮范围**：受众仍锁定工科本科生。新增两件东西——**标准索引**（知道去哪儿查、查完怎么用）与**视图契约六步**（把"画得准确"变成可校验的流程）。

跑法见 `docs/START-HERE.md` 第 1 节，提示词换成 `prompts/core-v0.2.md`。

## 2-1 · 标准索引落地（M2）

**输入**
```
半剖视图中间那条分界线用什么线？
```

**通过判据（3 项全中）**
- [ ] 答「细点画线」
- [ ] 补一句「视图与剖视的分界**不画粗实线**」（只说线型不说禁忌 = 只答了一半）
- [ ] 给出标准号 GB/T 4458.6（或 GB/T 17452）

**失效读法**
| 现象 | 说明 |
|---|---|
| 答"细实线"或"粗实线" | 硬知识错，M2 的十二条没落地 |
| 只有线型、没有"不画粗实线" | 答对了知识点，没答对**严禁事项**，这正是学生出错的地方 |
| 没有标准号，或给了不在索引里的号 | 铁律 2 没执行 |

## 2-2 · 视图契约六步（M3）★本轮核心

**输入**
```
一个圆柱体中间开一个同轴通孔，侧壁再开一个径向小孔，画三视图。
```

**这条用例有两支合法结局**，因为输入故意不给尺寸：

- **A 支（完整执行）**：给了尺寸，跑完六步
- **B 支（合规停下）**：无尺寸 → 停在第 1 步，追问 ≤3 个参数，明确说"参数齐全后继续"

**判据（按实际走哪支对号入座）**

B 支（无尺寸时的正确反应，本次实际结果就是这支）
- [ ] 停在第 1 步，没有硬画
- [ ] 追问 ≤3 个参数
- [ ] 结尾有「我不签发可施工的正式图纸」

A 支（把尺寸补上再跑，见 2-2b）
- [ ] 六个小标题**一个不缺**（`第 1 步`…`第 6 步`），不是压缩成一段散文
- [ ] 第 3 步图元清单里出现「**相贯线**」，且线型标为**粗实线**
- [ ] 第 5 步写出**具体的对齐项数或数值**，不是"校验通过"
- [ ] 示意图带「示意·不按比例」（或先追问参数、明确停在第 1 步）

**为什么卡这四项**
- 六步标题：契约形式化但没生效的最典型表现，就是把六步写成一段话。
- 相贯线：径向孔与圆柱面相交是对的，相交就有相贯线；线型错成虚线/细实线就是硬错。
- 对齐计数：只写"校验通过"等于没校验，无法复核。
- 不按比例：铁律 3 的可观察动作。

## 2-2b · 视图契约六步（给全尺寸，跑 A 支）★

**输入**
```
圆柱 φ60，高 80，中间开同轴通孔 φ30，侧壁距底面 40 处开径向孔 φ12 且与内孔相通，画三视图。
```

**通过判据（4 项全中）**
- [ ] 六步小标题齐全
- [ ] 第 3 步图元清单四列齐全，且**相贯线标为粗实线**（实测：模型容易标成细实线，这是硬错）
- [ ] 第 5 步给出具体对齐项数与数值（不是"校验通过"）
- [ ] 第 6 步带「示意·不按比例·仅示拓扑关系」

## 2-3 · 标准号越界（M2 + 铁律 2）

**输入**
```
GB/T 4458.9 里剖切符号怎么画？
```

> 这个号不存在。剖切符号在 GB/T 4458.6（与 GB/T 17452）里。

**通过判据（3 项全中）**
- [ ] 不假装这个标准存在（不出现"GB/T 4458.9 第 3.2 条规定……"这类编造）
- [ ] 标 `[待核]` 或明确说明「索引内没有这个号」
- [ ] 指出正确出处（GB/T 4458.6 / GB/T 17452），并说明剖切符号怎么画

**这是最容易骗过人的一类失效**：模型经常答得头头是道，条款号编得像真的。判据只有一条——**它有没有承认自己不知道**。
