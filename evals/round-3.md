# 第 3 轮验收（成图版式 · M5 提前）

**这一轮的由来**：用户给了一张样板图（`7-24(3) 带切口立体的侧面投影 —— 作图过程`），要求"每次回答都按这个标准"。
所以本轮不装 M4 四模式，先把**输出形态**锁死——版式是可见的，比模式标记更容易验收。

规范全文：`references/output-layout.md`；SVG 骨架：`assets/three-view-template.svg`。

## 3-1 · 六件套齐全（决定性的那条）

**输入**
```
长方体 80×50×40（长×宽×高，长沿 X、宽沿 Y、高沿 Z）。从左端面起长 40、从上表面向下 20、贯穿整个宽度 50，切去一个台阶。画三视图，按版式规范输出。
```

**通过判据（6 项全中）**
- [ ] **① 立体形成过程**：说明了原形、切去什么（位置/尺寸/贯通与否）、切完在哪个视图上出现什么特征
- [ ] **② 观察方向**：写清从哪个方向看、可见哪几个面、与哪个视图的对应关系
- [ ] **③ 三视图逐视图图元**：主/俯/左各列 粗实线 / 细虚线 / 细点画线
- [ ] **④ 三向对位校验**：长对正、高平齐各给出**对齐项数**；宽相等写成「俯视图 Y=__ → 45° 线 → 左视图 Y=__」
- [ ] **⑤ 尺寸表**：五列（代号/类型/数值与公差/基准/说明），三类尺寸齐全
- [ ] **⑥ 图例**：四种线型全列，且用词与正文一致

**附加（不达标也算过，但要记）**
- 六步与六件套不重复输出（v0.3.1 的映射规则）
- 结尾有「示意·不按比例」与「我不签发可施工的正式图纸」

**为什么卡这六项**：样板图的价值全在信息顺序上，不在答案。少了①，学生只会抄答案；少了④，谁都看不出视图对不对；少了⑥，读者不知道你在用哪套线型约定。

## 3-2 · 输入有歧义时的正确反应（顺带验证铁律 7）

**输入**（故意含歧义：「左前方一块」）
```
圆柱 φ60、高 80。上部切去左前方一块（距轴线 20、高 30、前后贯通），底部四周再切去，只留 50×30×20 的凸台。画三视图。
```

**实跑结果**：停在第 1 步，追问 2 个问题（切割平面属于哪种方案 / 凸台定位与高度方向），没有硬画。

**通过判据**
- [ ] 追问 ≤3 个，且问在点上（是"这块由哪些平面界定"这种真歧义，不是"请给出所有尺寸"）
- [ ] 没有在参数不明时输出三视图
- [ ] 说明"明确后按六步继续"
