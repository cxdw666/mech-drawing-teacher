# 第 4 轮验收（M4 四模式 + M6 异常降级 + M7 固定尾）

**本轮装了什么**：`prompts/core-v0.4.1.md`（6.2k 字，M0–M7 全装）
- M4 四模式：首行 `【模式】讲解/判图/出题/成图` + 各模式骨架
- M6 异常：图像输入三情形、矛盾检测判据、六行降级表、不确定标注
- M7 固定尾：末尾两行必须依次是 `【自检】…` 与 `我不签发可施工的正式图纸`

---

## 4-1 · 首行模式标记（判图分支）

**输入**：`这道题我画的三视图你看看对不对：主视图是个矩形，俯视图是个圆，左视图是个矩形。`

**通过判据（4 项全中）**
- [ ] 首行是 `【模式】判图`
- [ ] 五段齐全：总体判断 / 致命错误 / 规范问题 / 优化建议 / 订正后要点
- [ ] 明确写「无致命错误」而不是「基本正确」
- [ ] 末尾有带证据的【自检】行

---

## 4-2 · 讲解模式六段

**输入**：`为什么半剖视图中间的对称线要用点画线而不是粗实线？`

**通过判据**
- [ ] 首行 `【模式】讲解`
- [ ] 六段齐全：一句话结论 / 标准依据 / 为什么 / 图示化说明 / 易错点 2 条 / 自测一问（附答案）
- [ ] 「为什么」段从投影原理推出，不是背结论
- [ ] 给了标准号

---

## 4-3 · 超范围降级 + 固定尾

**输入**：`帮我算一下这根轴的疲劳寿命，材料 45 钢。`

**通过判据**
- [ ] 明确说明超出本课程范畴，不硬算
- [ ] 给替代价值（图上该标注什么）
- [ ] 末尾两行：`【自检】…` + `我不签发可施工的正式图纸`

**实测**：v0.4 只有 135 字，**漏了自检行**；v0.4.1 把两行定为"固定尾、短答也不例外"后，输出 805 字，六段讲解 + 自检 + 收口句齐全。

---

## 4-4 · 出题模式评分点可判定

**输入**：`给我出一道补画第三视图的题，带评分标准。`

**通过判据**
- [ ] 字段齐全：题目 / 已知条件 / 要求 / 参考答案 / 评分点 / 难度
- [ ] 每个评分点**可判定**（如「画出相贯线且线型为粗实线，2 分」），不出现「表达清晰 2 分」
- [ ] 自己解过一遍
