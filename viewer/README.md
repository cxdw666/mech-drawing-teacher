# 三维查看器（零依赖）

## 这是什么

把「三视图/立体描述」变成**可旋转的网页**：`viewer/models/*.json` → `viewer/pages/*.html`，双击即可看，也可以用本地服务器给链接。

## 为什么不用 three.js

three.js 和 CSG 库都要从 CDN 加载，本机网络对 jsdelivr/unpkg 是**完全不通**的（实测 HTTP 000）。所以这里走了另一条路：

- **布尔运算**：体素化。把包围盒切成边长 `cell` 的小方块，逐个判断"在不在实体内"，按 `base → add → sub` 顺序覆盖，再只保留暴露在外的面。
- **渲染**：Canvas 2D 软件渲染，画家算法排序 + 平面光照 + 背面剔除。

好处：**零依赖、离线可用、布尔结果正确**。代价：边缘有体素锯齿（`cell` 越小越细），不适合当工程图。

## 用法

```bash
node tools/make3d.mjs viewer/models/724-3.json     # 生成页面
node tools/serve.mjs 8770                          # 起服务
# 打开 http://127.0.0.1:8770/viewer/pages/724-3.html
```

## 立体描述 JSON 格式

```json
{
  "id": "724-3",
  "title": "标题",
  "subtitle": "一句话说明",
  "unit": "mm",
  "cell": 2.0,
  "bounds": { "min": [-60, -2, -60], "max": [60, 120, 60] },
  "solids": [
    { "op": "base", "shape": "cylinder", "r": 50, "h": 118, "pos": [0, 59, 0] },
    { "op": "sub",  "shape": "box", "size": [30, 45, 120], "pos": [-45, 102.5, 0] },
    { "op": "add",  "shape": "box", "size": [88, 30, 48], "pos": [0, 15, 0] }
  ],
  "dims": [{ "label": "Φ100", "note": "圆柱外径" }],
  "views": { "主视图": "……", "俯视图": "……", "左视图": "……" }
}
```

坐标约定：**x = 左右，y = 高度，z = 前后**；`pos` 是基本体中心；`op` 三选一：

| op | 含义 |
|---|---|
| `base` | 起始实体 |
| `add` | 并（加凸台、加肋） |
| `sub` | 差（切槽、钻孔） |

**顺序有影响**：数组按顺序执行，先加后减与先减后加结果不同。

### rotation（可选，角度制，XYZ 顺序）

| 方向 | rotation | 俯视图/主视图/左视图 上看起来 |
|---|---|---|
| 竖直轴（默认） | 不写 | 俯视图是一个圆 |
| 沿 X 轴（左右贯穿） | `[0,0,90]` | 左视图是一个圆 |
| 沿 Z 轴（前后贯穿） | `[90,0,0]` | 主视图是一个圆 |

**两条经验规则**：切割体两端各多伸出 ≥2 mm（避免端面共面退化）；`bounds` 各向外扩 5–10 mm（避免切面被裁）。

## 局限

- 体素近似：斜面、相贯线是阶梯状，**不是精确曲面**
- 只支持 box 与 cylinder 两种基本体（够覆盖大多数课程题）
- 不能代替 CAD，输出也不含尺寸标注
